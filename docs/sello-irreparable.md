# Sello de equipos irreparables

En Técnico y extensión → Partes de reparación, «Añadir sello IRREPARABLE» está activado por defecto.
Solo se marca el HTML de una OT cuyo desecho se haya verificado. CLOSE por sí solo no lo acredita.
Se conserva evidencia local separada de los estados importados; también se recuperan resultados históricos verificados de MD.
Si no hay evidencia local, se imprime sin sello. No se deduce el desecho de palabras en la avería ni de un simple cierre.

- Desde MD: el parte HTML con sello prepara la sesión de impresión en color. Sin sello o con la opción desactivada, blanco y negro.
- Desde la extensión: mantiene blanco y negro. No abre otra sesión para cambiar el color.
- Boixeres: ambas variantes HTML llevan el sello cuando corresponde.
- El PDF nativo de BIRT permanece sin modificar.

El cambio de preferencia se aplica a las nuevas sesiones de Edge. No cambia la impresora predeterminada ni su configuración global.
La confirmación del desecho y la impresión son independientes: un fallo de impresión nunca repite la operación irreversible.
